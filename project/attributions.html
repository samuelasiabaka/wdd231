Attributions and data notes

Sources and implementation notes for the Nigeria Demographics Explorer.

Data and editorial note

The project includes a local JSON dataset of Nigerian state and FCT records adapted from the data supplied with the original student project. Population and area values should be treated as illustrative estimates, not current official statistics. State-level cultural and language summaries are simplified and are not intended to represent every community.

External references

  • National Population Commission of Nigeria - consult for official population information and census updates.
  • National Bureau of Statistics - consult for official statistical publications.

Design and implementation

Original HTML, CSS, and JavaScript were written for this learning project. No third-party CSS frameworks or JavaScript libraries are used. The favicon is an original SVG mark created for the project.
