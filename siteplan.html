Site Name

Nigeria Demographics Explorer

This name was chosen because it clearly communicates the website's focus: an interactive, educational tool for exploring Nigeria's population, ethnic diversity, languages, and state-level demographic data. The word "Explorer" signals that the site is interactive and user-driven rather than a static information page.

Optional domain: nigeria-demographics.org

Site Purpose

The Nigeria Demographics Explorer serves as an interactive educational hub that makes Nigeria's demographic data accessible, engaging, and easy to understand. The site provides:

  • Key Statistics: Animated stat cards displaying Nigeria's population, major ethnic groups, official languages, and age distribution on the home page.
  • State Explorer: A searchable, filterable database of all 36 states and the FCT with population estimates, dominant languages, and ethnic composition.
  • Quiz Challenge: An interactive multiple-choice quiz that tests users' knowledge of Nigerian demographics with scoring and a local leaderboard.
  • Compare States: A side-by-side comparison tool for analyzing demographic differences between selected states.
  • Feedback Form: A standards-compliant HTML form for users to submit corrections, suggestions, or additional data.

The site targets students, researchers, educators, and anyone curious about Nigeria's place as Africa's most populous nation.

Scenarios

Scenario 1 - The Student Researcher "I am writing a paper on ethnic diversity in West Africa. Which Nigerian states have the highest population, and what are the dominant languages and ethnic groups in each? Can I filter and compare states side by side?"
Scenario 2 - The Curious Visitor "I want to test my knowledge about Nigeria. Is there a fun way to learn demographic facts through a quiz? Can I save my score and try to beat it later?"
Scenario 3 - The Educator "I need a reliable, visually clear source of Nigeria's demographic data to share with my class. Does this site work well on a projector and on students' phones? Is the information accurate and properly cited?"
Scenario 4 - The Data Enthusiast "I want to see visual representations of Nigeria's demographic data. Are there charts or graphs showing population distribution by region or language prevalence?"

Color Schema

The palette draws from Nigeria's national identity - green from the flag representing agriculture and natural wealth, paired with a warm amber accent for energy and visibility. High contrast ensures accessibility.

Deep Forest Green - #1B5E20 Primary brand color. Used for headings, navigation background, footer, section titles, and primary buttons.
Amber Accent - #FF8F00 Accent and call-to-action color. Used for buttons, links, borders, highlights, quiz score badges, and interactive element hover states.
Light Mint - #E8F5E9 Secondary background for cards, info boxes, and subtle section differentiation. Provides visual rest between content blocks.
Charcoal - #212121 Primary text color for body copy and paragraphs. Ensures strong readability against light backgrounds.

Typography

Technical Implementation Plan

This section outlines the technical architecture and key features that will be implemented to meet WDD231 project requirements.

Data Architecture

  • External JSON Data: State demographic data will be stored in a separate data/states.json file
  • Fetch API: Asynchronous data retrieval using fetch() with try...catch error handling
  • 15+ Items: 37 states and FCT, each with 7+ data properties (name, capital, region, population, area, ethnic groups, languages)

JavaScript Features

  • ES Modules: Code organized into modular files with import/export statements
  • Array Methods: Using map(), filter(), and forEach() for data processing
  • Template Literals: Dynamic HTML generation with template strings
  • Local Storage: Persisting quiz scores, user preferences, and favorites
  • Modal Dialogs: Accessible modal using the native <dialog> element

Page Structure

  • index.html: Landing page with animated statistics and overview
  • explore.html: Interactive state explorer with search, filter, and sort
  • quiz.html: Interactive quiz with leaderboard
  • compare.html: Side-by-side state comparison tool
  • form.html: User feedback form (with form action page)

CSS Features

  • CSS Animations: Keyframe animations for stat counters, card entrances, and modal transitions
  • CSS Grid & Flexbox: Responsive layouts for all screen sizes
  • CSS Custom Properties: Consistent theming with CSS variables
  • Responsive Design: Mobile-first approach (320px+) with no horizontal scrolling

Accessibility & Performance

  • Semantic HTML: Proper use of header, nav, main, section, article, and footer
  • ARIA Labels: Screen reader support for interactive elements
  • Lazy Loading: Images use loading="lazy" attribute
  • Optimized Assets: All images optimized, page weight under 500KB
  • Favicon: Custom favicon matching site branding
